Personal backup connection

Recovery information for THE BOSS.

This site explains a personal Google Drive connection used by the account owner to prepare an encrypted off-site backup of THE BOSS. It provides information about the connection and its data practices. It does not provide a public backup service, sign-in page or access to any backup.

Current status: the connection has been used for read-only account and storage-capacity checks. Backup uploads have not been enabled.

What the connection is for

The intended use is to store and retrieve encrypted backup repositories in the owner's Google Drive. The desktop tools are rclone, which connects to Drive, and restic, which encrypts backup contents locally before any authorised upload. Recovery would decrypt the backup locally using a separately held repository password.

Why Google Drive access is requested

The connection requests only https://www.googleapis.com/auth/drive.file. This allows access to files created by, or explicitly made available to, this app. The permission supports creating, reading, updating and deleting those files. It does not grant access to every existing Drive file, Gmail or Google Photos.

Storage-capacity and account information are used to confirm the intended account and available space. No broader Google permission is requested for this backup connection.

Privacy and account control

Read the privacy policy for details about Google data access, encrypted storage, credentials and retention. The owner controls authorisation and any future backup transfers. The public website contains no backup contents, credentials or recovery secrets.
